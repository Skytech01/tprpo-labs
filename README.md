# Технология разработки ПО — лабораторные работы

Вариант 3. Язык — Python 3.9+. Для рисунков нужна библиотека matplotlib
(`pip install matplotlib`).

| Каталог | Работа | Задание |
|---|---|---|
| `lr4` | ЛР 4. Реализация | Решение комбинаторно-оптимизационных задач: задача коммивояжёра, кратчайший путь, минимальное связывающее дерево |
| `lr6` | ЛР 6. Качественное ПО | n-й элемент последовательности Фибоначчи |
| `lr7` | ЛР 7. Стиль программирования | Нормальная выборка, разности соседних элементов, среднее, дисперсия, гистограмма |
| `lr8` | ЛР 8. Модульное проектирование | БД «Наряд»: добавление, корректировка, удаление, поиск, 2 формы отчётов + подключаемая 3-я |
| `lr9` | ЛР 9. Отладка и тестирование | Интеграл ∫(ln x)³/x dx методом трапеций с точностью ε |

## Запуск

```
cd lr4 && python main.py                  # меню программы
cd lr4 && python -m unittest discover -s tests
cd lr6 && python fibonacci.py 100
cd lr7 && python normal_diff_stats.py 2026
cd lr8 && python main.py
cd lr9 && python integral.py 1 2.718281828 1e-6 integral.png
```

Тесты в lr6–lr9: `python -m unittest` в каталоге работы.

## Модель ветвления (Git Flow)

- `master` — только выпущенные версии, каждая отмечена тегом (`v1.0`, `v1.0.1`, `v1.1`);
- `develop` — основная ветка разработки;
- `feature/*` — отдельная ветка на каждую лабораторную работу, вливается в `develop`;
- `release/*` — подготовка версии, вливается в `master` и обратно в `develop`;
- `hotfix/*` — срочное исправление выпущенной версии, ответвляется от `master`.
